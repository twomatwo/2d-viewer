# 2D Viewer 源码安装与使用

适用相机：FLIR Blackfly S BFS-U3-51S5C-C，Windows 11 x64。源码包为根目录的 `twodviewer/`，无需进入额外的 App 子目录。

## 首次安装

1. 安装匹配的 Spinnaker SDK、USB3 驱动和 Python 3.12 x64，详见 [相机依赖说明](camera-dependencies.md)。
2. 准备官方 PySpin wheel，放在根目录 `dependencies/`，或使用 `-PySpinWheel` 指定其位置。
3. 在**仓库根目录**打开 PowerShell，执行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
   ```

   可用 `-Python "C:\路径\python.exe"` 指定 Python，`-PySpinWheel "C:\路径\spinnaker_python-4.4.0.246-cp312-cp312-win_amd64.whl"` 指定 wheel。脚本在根目录创建 `.venv` 并按 `requirements.txt` 安装依赖。本机已有 `.venv-camera` 可继续由启动脚本使用。
4. 在 SpinView 中停止采集，双击根目录 `Start 2D Viewer.cmd`；也可执行 `python -m twodviewer --connect`。离线启动使用 `python -m twodviewer --no-connect`。

源码版新数据默认在根目录 `data/`；已有 `LabView-App` 数据目录自动保留原位使用。新配置名为 `settings/twodviewer.json`，旧 `settings/labview.json` 继续兼容；显式 `--data-directory` 优先。安装版数据仍在 `%LOCALAPPDATA%\LabView`，与源码目录分开。所有数据与依赖目录均不上传 GitHub。

## 标注布局（源码版 0.14.1）

顶栏“移动视野”和“选择标注”用于切换鼠标模式。点击“选择标注”会打开右侧标注页，即使当前已是选择模式也能重新打开；测量长度、面积、标记点、文字、线条、矩形、椭圆、画笔及图片导入统一在该页操作。

标注页顶部提供选择标注、撤销／重做。下面分为两个工具区，按钮均配线条图标，当前工具以绿色边框高亮：

- **测量**：测量长度、测量角度、测量面积。角度测量依次点击第一条边上的点、顶点、第二条边上的点，结果为 0°–180° 夹角，不依赖长度标定；右键或 Esc 取消。面积测量用左键逐点圈选多边形，右键或双击完成，显示面积及平均 RGB。
- **绘图标注**：矩形、椭圆、线条、多边形、标记点、文字、画笔及图片导入。独立“多边形”只画闭合轮廓，右键或双击完成，不产生测量读数。

面积的平均 RGB 统计完成圈选时的**底图显示像素**（0–255，已包含电脑端调色及方向处理），不包含图片等叠加标注；使用 OpenCV 多边形掩膜，包含边界像素。几何面积与取样像素数分别记录，数值可能不同。面积、角度和 RGB 均随创建时的记录保存；移动、缩放、旋转、切换画面或调色不重新取样。RGB 在图片、列表和所选属性中显示；完整读数、像素数及取样依据可在列表悬停查看，并随测量 CSV、拍照记录和自动恢复记录保存。旧面积记录缺少 RGB 时保持未记录，不重新取样。

统一颜色设置位于绘图工具下方；选择／组合和对象属性集中在分隔线下，底部保留删除／清空及 PNG／CSV 两行按钮。

选择对象后显示选择数量及组合／取消组合；选中图片时显示不透明度，选中测量时显示原始数值及创建倍率。选中标注后可精确输入角度和等比例缩放（保留三位小数）；图片 100% 对应导入原图像素，正角度为顺时针。组合／多选以列表第一项的角度和缩放为数值基准，围绕整体中心变换并保留相对位置，支持撤销／重做，不重新计算原始测量值。

对象列表随窗口高度伸缩。选中一个组合后，点击底部“导出组合 PNG…”选择保存位置：只绘制该组标注（含图片与测量文字），背景透明，按内容范围裁切并留少量边距；不含相机画面、比例尺、选择框或相机元数据。图片自身透明度及设置的不透明度均保留。空选、未组合对象或同时选择多个组时导出按钮不可用。底部另保留删除、清空和测量 CSV 导出。Ctrl+Z、Ctrl+Y／Ctrl+Shift+Z 及原有工具快捷键继续有效；输入框内的文字撤销优先由输入框处理。

本次仅更新源码，已交付安装包仍为 0.10.2。

## 使用和数据

- 未连接相机时，可以点击“打开图像…”查看和处理已有图片，也能进行标注和测量。
- 相机参数直接控制采集。电脑处理只改变显示和 PNG 的颜色、亮度、对比度及方向。
- 测量前选择物镜并用已知长度标尺校准一次；各倍率分别记忆。相机或采样改变时需要匹配的标定。
- 测量与标尺校准使用黑白描边十字光标，适应浅色及深色背景；中心留空处为测点。
- 电脑处理页的直方图显示通道与下方调节通道双向同步；选择 RGB 三通道叠加时调节整体色阶。整体和 R／G／B 各自保留黑白点，Gamma 为整体调节。
- 顶栏“拍照”填写文件名和保存位置；“快速保存”按右侧配置的目录和命名规则保存。格式和标注选项在“拍摄保存”页统一配置，默认 F9 为快速保存，可在快捷键设置中修改。
- `settings` 保存正式设置和标定；`captures` 默认保存照片／录像；`logs` 保存故障记录。备份标定时可在“设置 → 物镜与标定 → 物镜标定…”中导出标定库。
- 本程序只有真实相机入口，连接失败会报告原因。

## 拍照与快速保存（源码版 0.10.0）

“拍摄保存 → 图像保存选项”统一选择 PNG／原始 TIFF 和是否保存标注、测量线及比例尺；工具栏的两个保存按钮共用这些选项。PNG 保留当前电脑处理结果，勾选标注时绘入图像；TIFF 保留原始像素和位深，勾选时仅把标注及比例尺信息写入文件内部记录，不改变原始像素。不额外生成 JSON 文件。

- **拍照**：打开文件保存窗口，填写文件名并选择位置；取消不保存，覆盖已有图像需要确认。文件格式由右侧设置决定；手动选择的位置不会改变快速保存目录。
- **快速保存**：直接使用配置的目录和命名规则，无需弹窗。格式、标注、目录、规则及下次序号会保存，重启后仍有效。

快速保存的命名模板可以混合样品名称与字段，自由调整前后顺序；点击“日期／时间／序号／物镜”按钮在输入光标处插入字段。例如 `{date}_样品A_{seq}_{objective}` 可生成 `20261027_样品A_0001_50x.png`。`{time}` 为时分秒；物镜倍率取自拍摄画面的记录，冻结或离线图像不会误用后来选择的其他物镜。

“日期与序号设置”可配置日期格式、下一序号、补零位数、递增步长，以及是否每天从指定序号重新编号。文件名预览实时更新。仅快速保存成功后推进序号；取消或失败不推进。同名文件不会自动覆盖：有序号字段时跳过已用序号，没有序号字段时追加 `_2`、`_3` 等后缀。非法字段或文件名会在预览处提示，修正后才能快速保存。

## 物镜与相机参数方案（源码版 0.9.1）

1. 窗口上方只保留一行常用操作工具栏；点击该栏的“设置 → 物镜与相机参数…”，配置实验室实际物镜的名称、倍率、启用状态和排列顺序。同倍率的不同物镜应使用不同名称；改名保留标定和方案，移除的记录保留在本机归档中。
2. 在常用操作栏直接点击当前实际使用物镜的按钮，与标定窗口的物镜选择同步。原来的独立菜单栏、物镜与方案横栏已移除。
3. 原横栏中的相机方案选择、保存、恢复及修改状态在右侧“相机参数 → 物镜相机参数”；方案维护在左上角“设置 → 相机与方案”。首次使用时连接真实相机、调好参数后，点击该区域的“保存修改”命名保存。每个物镜仍可保存多套相机方案；“设置 → 相机与方案 → 另存为相机方案…”创建新方案，“恢复已保存”恢复最近保存的模式及参数。
4. 同一会话中切换物镜／方案会分别保留临时相机调整，切回来可以继续；重启默认载入正式保存的方案，通过“设置 → 相机与方案 → 恢复上次临时调整”可找回临时状态。程序不能识别或转动物理物镜，请核对实际安装的物镜。

保存范围是相机支持的成像参数，包含曝光／增益／白平衡模式、手动值、自动控制设置、相机端 Gamma／黑电平／颜色配置、像素格式、ROI、采样及适用的通道／查找表值。使用 SDK 标准成像分类补足该机型未标记为可持久化的参数。不可读取的参数会明确提示；命令、文件操作和运行时计数不会作为成像方案执行。不同相机、外触发模式或当前程序不支持的像素格式不会被当作兼容方案静默载入。

自动曝光、自动增益、自动白平衡开启时，自动产生的数值变化不会标记“临时修改”；模式开关或用户设置与保存方案不同则会标记。恢复手动曝光方案会同时关闭自动曝光并写回原曝光值。未启用的帧率限制及触发设置所产生的派生读数会记录，但不强制写回或用于修改判定。方案必须回读核对成功才显示一致；失败会尝试恢复原配置并暂停使用标定。

“设置 → 相机与方案”可以导出当前已保存方案、当前物镜全部方案或全部物镜与方案。载入 JSON 文件时可以合并或全部另存为新物镜；先导入库，再选择方案／点击“恢复已保存”应用，不会同时导入电脑处理或标定。标定库在“设置 → 物镜与标定 → 物镜标定… → 手动填写比例 / 标定库”单独导入／导出，分别保留相机与采样匹配的记录。

电脑处理设置（包括上下／左右镜像、旋转及调色）自动保存为应用偏好，下次启动恢复，不写入物镜相机方案。保存、恢复或导入导出相机方案不会带入电脑处理；相机自身的 Gamma 属于相机参数，与电脑处理页的 Gamma 相互独立。“电脑处理 → 恢复默认 · 不做额外电脑处理”一次恢复全部 RGB、色阶、Gamma、亮度、对比度、饱和度、灰度及方向设置，不改相机或标定。原“重置直方图调整”仍只恢复色阶和 Gamma。

切换物镜／方案需要先停止录像和定时拍照。切换物镜默认保留全部标注及测量，不再弹出丢弃确认；同一物镜内更换会改变采集区域的方案仍先询问是否保存。冻结画面和本程序保存的离线图像保留原画面的物镜／参数记录及标定，不会套用新物镜。PNG／原始 TIFF 内记录实际使用的相机配置、方案版本和电脑处理；逐帧读数以 SDK 提供的 chunk 字段为准，其余字段为最近回读。原始 TIFF 像素保持不变。

已有配置首次写入前备份为 `settings/labview.before-objective-profiles.json`，保留旧物镜、标定、预设和快捷键。原来的混合预设只迁移相机部分，电脑处理不再随预设恢复。桌面的“2D Viewer（源码版）”入口使用本仓库最新源码；旧版安装包需另行构建才包含这些改动。

## 快捷键

在菜单“设置 → 快捷键设置…”中修改主快捷键和备用键。点击按键框后直接按下组合键，点击框内 × 清除；冲突时不能保存。“恢复默认”也需要点击“保存”才会生效。绑定随本机设置保存，重启后仍有效。

常用默认绑定：

| 操作 | 快捷键 |
| --- | --- |
| 打开图像／拍照填写文件名／切换到原始 TIFF 后拍照 | Ctrl+O／Ctrl+S／Ctrl+Shift+S |
| 按配置的目录和命名规则快速保存 | F9 |
| 冻结／恢复显示 | 空格 |
| 开始／停止录像（使用拍摄保存页的录像帧率） | Ctrl+Shift+R |
| 适应窗口／100%／放大／缩小 | 0／1／+ 或 =／- |
| 移动视野／选择标注／测量长度 | H／V／M |
| 标记点／文字说明／矩形框 | P／T／R |
| 多边形面积 | G |
| 重做标注 | Ctrl+Y 或 Ctrl+Shift+Z |
| 组合／取消组合 | Ctrl+G／Ctrl+Shift+G |
| 撤销标注／删除所选对象／取消绘制或校准 | Ctrl+Z／Delete 或 Backspace／Esc |

删除快捷键在图像区域获得焦点时生效。输入框内的字母、数字和空格用于正常输入；弹窗内按键由弹窗处理。快捷键仅在本程序内生效，按住不重复触发。清空全部标注、重置处理参数和修改标定没有默认快捷键。

本机已准备的官方 PySpin wheel 约 67 MB，放在本机旧 `LabView-App/install`，由 Git 忽略；完成安装后可移走留作备份。Python、Qt、OpenCV、NumPy 和相机 SDK 的运行依赖仍需占用数百 MB，它们是正式程序运行所需。

本机开发目录的运行脚本会复用父目录已有的 `.venv-camera`；单独部署时优先使用本文件夹通过安装脚本创建的 `.venv`。


## 标注面积与自动恢复（源码 0.11.0）

工具栏提供撤销／重做；“更多标注”或右侧标注页选择“多边形面积”（G）。左键逐点绘制，右键用已有顶点闭合、不加点；双击添加最后一点并闭合，Esc 取消。面积按当前标定显示为 µm² 等平方单位，未标定时显示 px²；结果写入图像元数据及测量 CSV。

完成、删除、清空、撤销、重做标注或修改标定时，程序自动写入数据目录的 `recovery` 文件夹。每个有标注的视野在首次修改时保留一张原始 TIFF，此后的操作只更新对应 JSON 标注记录；切换物镜、方向或来源后使用独立记录，原视野继续保留。恢复背景是该视野首次标注时的图像，不是相机最新实时帧。恢复记录独立于拍照保存选项，也保留在正常退出后。

异常退出后，停止相机采集，从“设置 → 恢复自动保存的标注…”选择记录，即可离线恢复原图、标注、显示参数及标定，再继续编辑或拍照保存。不会把旧标注直接叠加到当前相机画面。恢复目录不自动删除历史视野，可在不需要时手动备份或清理成对的 TIFF／JSON 文件。尚未完成的绘制草稿不在恢复记录内。


## 测量并入标注（源码 0.11.1）

右侧页面统一为“相机参数、电脑处理、标注、拍摄保存”。长度、面积、文字与图形工具及结果统一在“标注”页，可一起选择、删除、清空、撤销和重做；测量 CSV 也从此页导出。物镜切换在顶栏，标定管理在“设置 → 物镜与标定 → 物镜标定…”，也可点击右侧标定状态按钮打开。

长度／面积显示如 `12.350 µm（20×）`、`156.800 µm²（40×）`，未标定显示如 `128.00 px（20×，未标定）`。每个测量对象固定保存创建时的物镜名称、倍率、ID、标定比例及单位；以后修改标定、切换物镜或恢复记录都不重算旧结果，新测量才采用当前画面的物镜和标定。图像内标注、结果列表、CSV 以及 PNG／TIFF 元数据使用相同规则。

切换物镜默认保留已完成的标注和测量及撤销历史，取消尚未完成的草稿；保留原图像像素坐标，不按倍率自动缩放或做图像配准。切换后会提示核对标注位置。自动保存分别保留切换前后视野的恢复记录；恢复记录中的混合倍率测量仍保留各自标定。更换图像来源或同一物镜下改变图像区域／方向仍沿用原来的新视野处理。


## 设置与日常操作分区（源码 0.11.2）

左上角“设置”按用途分组：

- **物镜与标定**：物镜名称、倍率、排序、启用状态；标尺校准、手动标定比例和单位、比例尺长度、标定库导入／导出。
- **相机与方案**：设备设置中的手动序列号；相机方案另存、核对、删除、导入／导出及临时调整恢复。
- **保存与命名**：命名模板、日期格式、序号位数、步长、每日重置和每日起始序号，带实时预览。
- **快捷键设置**：沿用原来的绑定编辑窗口。

右侧保留连接／停止／扫描、当前方案选择／保存修改／恢复已保存和标定状态，以及日常成像、测量、标注与拍摄操作。拍摄保存页保留目录、样品文字、下一序号、格式、标注开关和文件名预览。样品文字作为文件名前缀，非空时加一个下划线分隔；留空时原命名模板及文件名保持兼容，无需迁移旧模板中的样品文字。命名规则和样品文字实时保存，手动序列号在结束编辑时保存；恢复启动设置不改变相机方案、标定或旧标注。

标定和命名设置窗口可以关闭后重新打开。点击标定窗口的“用标尺校准当前物镜”会收起窗口，方便直接在图像上画标尺线；完成后输入实际长度。设置窗口不会阻塞预览，退出程序时一并关闭。


源码 0.11.3：顶部物镜改为直接点击的互斥按钮，当前物镜高亮；按钮名称、顺序和启用状态沿用“设置 → 物镜与标定 → 管理物镜…”。默认六个倍率在 1050／1480 宽窗口均直接可见。自定义物镜较多或名称较长时，该区域可滚轮横向浏览，切换后自动显示所选项。撤销／重做移到拍照操作之后，保持最小窗口下可见；工具栏仍为一行。拍摄保存页文件名预览下方增加命名模板设置路径提示。

## 标注选择与组合变换（源码 0.12.0）

长度测量、面积轮廓、文字和图形共用“标注颜色”，移除单独的测量线颜色。颜色入口设置后续绘制颜色；有选中对象时同时修改所选对象，可撤销。已有对象保留原颜色，直到主动修改。

选择“选择标注”（V），单击选中对象并拖动移动，Ctrl＋单击增减多选，拖动空白区域框选。侧栏树列表也支持 Ctrl／Shift 多选，并与图像选择同步。“组合”（Ctrl+G）将所选对象合并为一个整体；点击任一成员会选中整个组合。树中展开组合可查看成员，需先取消组合才能分别编辑成员。

选中后，拖动边框角点进行等比例缩放，拖动上方圆点围绕选择框中心旋转。单个图形及多个所选对象也可使用这些手柄。线宽、端点和标签字号保持屏幕显示大小，文字保持正向。拖动中按 Esc 取消本次变换，一次完成的拖动只占一步撤销；组合、取消组合、删除所选和颜色修改均支持撤销／重做。

组合只支持一层：选择多个已有组合或散落对象再组合，会合并成一个平级组合。“取消组合”（Ctrl+Shift+G）保留所有成员当前的位置、大小和角度；之后可继续独立选择和移动。

每个标注保留原始几何点，另外保存从原始点到当前显示位置的仿射变换和组合 ID。**缩放后，长度、面积、单位和倍率仍保留原始测量值，不按新轮廓重新计算**，结果列表的悬停提示说明此规则。新测量仍使用创建时画面的物镜及标定。

自动恢复保存组合和显示变换，兼容旧记录缺少这些字段的情况。PNG 按当前变换绘制图形与正向标签，原始 TIFF 像素不变；文件元数据记录原始坐标、变换、显示坐标和组合关系。测量 CSV 保持原来的数值列，追加组合 ID、显示变换及显示坐标。选择框和操作手柄只用于编辑，不写入保存图像。


## 导入图片标注（源码 0.13.0）

先连接相机或打开一张底图，在“标注”页点击“导入图片标注…”（顶部“更多标注”也有同一入口）。支持 PNG、JPG／JPEG，以及本机 Qt 图像插件支持的 BMP、WebP、TIFF 等静态图像。导入只增加叠加标注，不替换底图，也不改变相机原始数据。

导入窗口预览当前画面快照及已有标注，可设置不透明度、相对图片原始像素的等比例缩放百分比和旋转角度。默认不透明度 50%，较大的图片自动缩小到当前可见区域内，放在可见区域中心。0% 为完全透明，100% 为不透明；PNG 原有透明通道与此不透明度叠加。

导入后自动选中图片，沿用拖动移动、角点等比例缩放、顶部圆点旋转、组合／取消组合、删除与撤销／重做。侧栏的“图片不透明度”可继续调整，按回车或结束编辑时作为一步操作应用；选择包含多张图片的组合时，一起调整这些图片，不修改其中的线条、文字或测量对象。标注颜色不对图片染色。

图片以保留透明通道的 PNG 数据嵌入标注记录，移动或删除原文件不影响自动恢复。图片的原文件名、不透明度、变换和组合关系都能恢复。PNG 导出按当前状态绘入图片标注；原始 TIFF 不修改像素，仅在勾选保存标注时将图片及变换信息写入文件内部记录。导入不会递归携带原图的文字元数据或旧标注记录。

单张图片限制为 2000 万像素，并限制内嵌 PNG 编码大小；解码缓存按内存与数量限制复用，预览和逐帧显示不重复读取源文件。导入取消或读取失败时保留当前标注；切换物镜尚未完成时暂不导入。
