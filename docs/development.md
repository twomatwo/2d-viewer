# 2D Viewer 开发维护说明

Windows 11 桌面显微相机软件，FLIR BFS-U3-51S5C-C（USB3）。原名 LabView，当前产品名 2D Viewer。只维护主程序；未连接相机时使用主程序“打开图像…”进行离线查看、处理、标注和测量。当前源码版本为 0.14.1，交付安装包仍为 0.10.2；后续修改源码不自动重建安装包。

## 用户明确约束

- **2026-11-05 更名要求**：产品统一称为 2D Viewer，避免与其他 LabView 软件重名。窗口、应用名称、EXE、安装器、快捷方式、文档使用新名；2026-11-12 用户确认源码包改为 `twodviewer` 并扁平化；历史数据路径和序列化格式继续兼容。旧版安装器 AppId 不变，升级沿用安装路径并保留所有数据。

- 算法和底层功能优先调用成熟库、官方 SDK 或复用已有的可靠实现，例如 OpenCV 图像处理和官方相机接口；不要自行重写已有的高效算法。自写代码主要负责界面、参数关联和流程衔接。只有现成实现无法满足明确需求时，才编写必要的自定义部分，并验证正确性和实际性能。
- 不主动增加未要求的可见功能。图像下方只显示相机 FPS、实际绘制 FPS，以及图像尺寸、格式、曝光、增益、坐标和 RGB；不要帧序号、接收 FPS、处理中间 FPS、耗时、对焦分数。
- 明确区分相机参数与电脑处理。相机先选择自动／手动，再启用对应参数；鼠标未主动选择数值控件时滚轮不能改变它。
- 手动色阶：整体亮度和 RGB 输入直方图，不要处理后的直方图，不要自动拉伸；电脑端 R、G、B 都可独立调整。“重置直方图调整”只恢复整体和 RGB 各通道的黑点、白点及 Gamma，保留 RGB 增益、亮度、对比度、饱和度、灰度和方向等其他设置。
- 物镜在设置中自定义名称、倍率、顺序及启用状态；常用操作栏的物镜单击按钮与标定设置窗口的物镜单选列表同步。每个物镜分别保存相机方案与标定。2026-11-11 用户更新要求：测量整合进标注，长度／面积结果在图片及列表显示创建时倍率；切换物镜默认保留已完成标注与测量及其各自标定，保留原像素坐标，不自动配准。2026-11-11 追加：统一标注颜色，支持多选移动、单层组合／取消组合及等比例缩放／旋转，显示变换不重算原始长度与面积。比例尺固定实际长度，随标定和缩放改变像素宽度。缩放按钮显示百分比并可点击修改。
- **2026-10-27 布局要求**：移除最上方菜单栏，“设置”移到原常用操作栏；原第三行物镜／方案横栏移入右侧“相机参数”，保留方案选择、保存／恢复、修改状态及标定状态；2026-11-11 用户更新要求：低频标定、物镜管理、方案维护、命名规则及手动序列号统一移入左上角设置；原常用操作栏增加物镜选择，2026-11-11 更新为直接显示各物镜的单击按钮。上方最终只占一行工具栏，不应再增加其他横栏。相机参数方案和数据语义不随本次布局调整改变。
- **2026-10-26 参数方案要求**：用于 RGB 标定二维材料厚度，物镜方案只保存相机成像参数（包含模式和通道选择器值），不保存电脑处理。自动曝光／增益／白平衡的开关参与比较，自动输出数值不参与；临时打开原保存为关闭的自动模式必须显示修改。恢复手动方案必须同时恢复关闭状态及原数值。电脑处理自动保存为应用偏好（2026-11-11 用户更新要求），提供完整“恢复默认”，保留原来仅重置色阶／Gamma 的按钮语义。
- **2026-10-27 拍照保存要求**：顶栏保留“拍照”和“快速保存”两个按钮。“拍照”只弹出位置／文件名选择，文件名由用户填写；“快速保存”使用右侧目录及命名规则。两者的 PNG／原始 TIFF 和标注选项统一来自“拍摄保存”页，不能再弹出旧的格式／标注设置对话框。命名模板可自由组合日期、时间、序号、物镜倍率及样品文字，配置日期格式、序号位数、下一编号、步长和每日重置，并提供实时预览。默认 F9 快速保存，旧快捷键 ID 保持兼容。拍摄记录嵌入图像，不自动产生 JSON 附件。
- **最新用户要求：删除 Demo 程序和启动入口，不再维护或恢复模拟相机。离线使用由主程序打开图片完成；相机连接失败不得切换模拟。**
- 实验室交付 `release` 中的安装 EXE 和 HTML 安装／更新说明；源码只有根目录的 `twodviewer`。不要重新堆积旧环境、测试图片、SDK 文档或旧版打包副本。验证用临时文件并清理，只保留本次成品和可重复构建所需脚本。

## 核心实现与兼容约束

- 采集线程独占 SDK，原始数组在 image.Release 前复制；LatestBuffer 仅保留最新帧。处理事件唤醒，GUI 通知合并；实际绘制 FPS 以新帧完成 Qt 绘制计数。Frame 保留不可变配置、物镜／方案版本及代次，不能混入旧处理结果。内部帧身份不显示在界面。
- 相机方案位于 profile_controls.py／profile_dialogs.py，SDK 访问在 camera_features.py 和 acquisition.py，纯数据比较在 camera_profiles.py。不能依赖本机不完整的 IsStreamable 标记；按官方成像分类与选择器收集可读标量，排除命令、文件及运行时计数。访问选择器后必须恢复；自动模式恢复后仍需恢复选择器。不能无条件重置 ROI、启用帧率限制或用当前 IsAvailable 代替静态分类。未启用触发的派生值只记录，不强写。
- 配置恢复必须回读核对，失败尝试恢复并报告，不能显示已应用。自动输出数值不参与修改判定，模式开关参与；手动方案恢复必须同时关闭自动模式及恢复数值。同相机完整配置值（含全部选择器）严格相同时才允许不重启采集的上下文切换；临时方案避免重复写盘。
- settings_store.py 保留旧 settings.v1 schema，objective_entries 用稳定 ID，旧名称只作镜像；不能强加默认物镜。旧配置首次写入前保留 before-objective-profiles 备份；更改用 transaction 失败回滚。标定库 v2 保存全部采样上下文并兼容 v1，导入相机库不能带入电脑处理或标定。
- 标定按相机与 binning／decimation、Sensor／ISP 选择器层完整 sampling_features 匹配；全为 1 时兼容旧标定，ROI 裁切可沿用。换光路需要真实标定。冻结／离线图像使用自身物镜及拍摄标定，PNG 重开不能再 Bayer 解码。逐帧参数以 chunk 为准，其他为最近回读。
- 电脑处理自动保存到 preferences.display_settings；恢复默认覆盖全部处理字段，但不删相机方案或标定。饱和度等优先 OpenCV 原生运算，避免全幅浮点临时数组导致低 FPS；性能检查应包含实际 RGB／色阶／饱和度调整，不能仅验证默认设置。
- annotations 保留原始 points、创建时倍率／标定、group_id 和 transform。组合单层，多选统一增量变换；移动、旋转、缩放不重算测量。polygon 是历史面积 kind，polygon_shape 是纯轮廓；angle 三点以中点为顶点，返回 0–180 度。新增工具通过现有 QAction 和快捷键系统进入，不硬编码按键。
- 面积完成时 region_measurement.py 用 OpenCV 局部掩膜计算底图显示 RGB（0–255，含边界，不含标注）；mean_rgb 和 rgb_pixel_count 固定保存，不加入逐帧路径。全白均值需钳位消除浮点越界；旧记录缺 RGB 时不补算。几何面积与取样像素数分别记录。
- annotation_geometry.py 统一绘制、命中、变换与导出几何。annotation_icons.py 使用 Qt 原生线条图标，含普通／选中／禁用和高分屏分辨率；不引入图片生成资源。测量光标为按 DPR 缓存的 33 逻辑像素黑边白芯十字，中心留空，不放入导出或逐帧保存路径。
- 图片标注由 image_assets.py 经 QImageReader 自动处理 EXIF，归一化为自包含 PNG，保留 alpha、移除来源文字元数据，避免递归带入旧记录；限制 2000 万像素及 64 MiB 编码，解码缓存有内存和数量上限。图片不受统一颜色染色。
- 导出一个完整组合复用 paint_annotations，透明背景，合并图形与标签边界并留 5 px 边距；1:1 图像像素，最大 2000 万像素／单边 32767 px。检查整数转换前的范围；不读取相机帧、不画比例尺或选择框、不写相机元数据。QSaveFile 原子写入。
- 拍照固定点击时帧；PNG 绘制电脑处理及可选标注，原始 TIFF 不改像素、仅嵌入记录。保留 labview.capture.v1、PNG LabView 键等历史格式标识。自动恢复为每个视野原始 TIFF＋JSON，不能当缓存删除；包含图片资产、变换、组合、创建时测量及 RGB，兼容缺少新字段的旧记录。
- 命名逻辑在 capture_naming.py。只在成功保存后推进序号，失败／取消不推进；关闭等待保存也需完成推进，保存期间用户修改规则优先。自动保存不覆盖已有文件；使用同目录临时文件原子发布。无序号模板重名加后缀，有序号模板按步长跳号；不能恢复旧格式选择弹窗。
- 快捷键统一由 shortcuts.py 管理，主／备用键可清除、冲突禁止保存、无自动连发；输入框保留文字输入和自身撤销，弹窗处理自身按键，删除仅在图像区域默认生效。旧工具 ID、G 面积绑定、原 raw 快捷键语义兼容。
- 保留原生崩溃日志和错误释放流程。历史 shiboken6 访问异常根因尚未确认，不能宣称彻底修复；沙箱无硬件权限不能误判相机故障，不使用模拟相机代替硬件验证。
