# 2D Viewer 正式相机程序

适用相机：FLIR Blackfly S BFS-U3-51S5C-C，Windows 11 x64。

实验室日常安装和更新优先使用项目 `release` 中的安装 EXE 和《实验室安装与更新说明.html》，无需安装 Python。安装版数据在 `%LOCALAPPDATA%\LabView`，与本源码目录分开。

以下保留源码版的安装与运行方法；本文件夹也可单独复制到其他开发电脑。

## 首次安装

1. 安装官方 Spinnaker SDK 4.4.0.246 和相机驱动，确认 SpinView 能出图。
2. 安装 Python 3.12 x64，并安装 Python Launcher（`py` 命令）。
3. 在本文件夹打开 PowerShell，运行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
   ```

   安装需要联网下载界面和图像处理依赖；运行前请从官方获取匹配的 PySpin wheel，放入 `install`（详见 `install/README.md`），或通过 `-PySpinWheel "C:\路径\spinnaker_python-4.4.0.246-cp312-cp312-win_amd64.whl"` 指定。官方安装文件不随 GitHub 源码分发。也可用 `-Python "C:\路径\python.exe"` 指定 Python 3.12。安装脚本创建本文件夹下的 `.venv`。

4. 在 SpinView 中停止采集并断开相机，双击本文件夹中的 `Start 2D Viewer.cmd`。

## 使用和数据

- 未连接相机时，可以点击“打开图像…”查看和处理已有图片，也能进行标注和测量。
- 相机参数直接控制采集。电脑处理只改变显示和 PNG 的颜色、亮度、对比度及方向。
- 测量前选择物镜并用已知长度标尺校准一次；各倍率分别记忆。相机或采样改变时需要匹配的标定。
- 测量与标尺校准使用黑白描边十字光标，适应浅色及深色背景；中心留空处为测点。
- 电脑处理页的直方图显示通道与下方调节通道双向同步；选择 RGB 三通道叠加时调节整体色阶。整体和 R／G／B 各自保留黑白点，Gamma 为整体调节。
- 顶栏“拍照”填写文件名和保存位置；“快速保存”按右侧配置的目录和命名规则保存。格式和标注选项在“拍摄保存”页统一配置，默认 F9 为快速保存，可在快捷键设置中修改。
- `settings` 保存正式设置和标定；`captures` 默认保存照片／录像；`logs` 保存故障记录。备份标定时可在测量页导出标定库。
- 本程序只有真实相机入口，连接失败会报告原因。

## 拍照与快速保存（源码版 0.10.0）

“拍摄保存 → 图像保存选项”统一选择 PNG／原始 TIFF 和是否保存标注、测量线及比例尺；工具栏的两个保存按钮共用这些选项。PNG 保留当前电脑处理结果，勾选标注时绘入图像；TIFF 保留原始像素和位深，勾选时仅把标注及比例尺信息写入文件内部记录，不改变原始像素。不额外生成 JSON 文件。

- **拍照**：打开文件保存窗口，填写文件名并选择位置；取消不保存，覆盖已有图像需要确认。文件格式由右侧设置决定；手动选择的位置不会改变快速保存目录。
- **快速保存**：直接使用配置的目录和命名规则，无需弹窗。格式、标注、目录、规则及下次序号会保存，重启后仍有效。

快速保存的命名模板可以混合样品名称与字段，自由调整前后顺序；点击“日期／时间／序号／物镜”按钮在输入光标处插入字段。例如 `{date}_样品A_{seq}_{objective}` 可生成 `20261027_样品A_0001_50x.png`。`{time}` 为时分秒；物镜倍率取自拍摄画面的记录，冻结或离线图像不会误用后来选择的其他物镜。

“日期与序号设置”可配置日期格式、下一序号、补零位数、递增步长，以及是否每天从指定序号重新编号。文件名预览实时更新。仅快速保存成功后推进序号；取消或失败不推进。同名文件不会自动覆盖：有序号字段时跳过已用序号，没有序号字段时追加 `_2`、`_3` 等后缀。非法字段或文件名会在预览处提示，修正后才能快速保存。

## 物镜与相机参数方案（源码版 0.9.1）

1. 窗口上方只保留一行常用操作工具栏；点击该栏的“设置 → 物镜与相机参数…”，配置实验室实际物镜的名称、倍率、启用状态和排列顺序。同倍率的不同物镜应使用不同名称；改名保留标定和方案，移除的记录保留在本机归档中。
2. 在常用操作栏的“物镜”下拉框选择当前实际使用的物镜，与测量页选择同步。原来的独立菜单栏、物镜与方案横栏已移除。
3. 原横栏中的相机方案选择、保存、恢复、方案管理、修改状态和标定入口，统一移入右侧“相机参数 → 物镜相机参数”。首次使用时连接真实相机、调好参数后，点击该区域的“保存修改”命名保存。每个物镜仍可保存多套相机方案；“方案管理 → 另存为相机方案…”创建新方案，“恢复已保存”恢复最近保存的模式及参数。
4. 同一会话中切换物镜／方案会分别保留临时相机调整，切回来可以继续；重启默认载入正式保存的方案，通过右侧“方案管理 → 恢复上次临时调整”可找回临时状态。程序不能识别或转动物理物镜，请核对实际安装的物镜。

保存范围是相机支持的成像参数，包含曝光／增益／白平衡模式、手动值、自动控制设置、相机端 Gamma／黑电平／颜色配置、像素格式、ROI、采样及适用的通道／查找表值。使用 SDK 标准成像分类补足该机型未标记为可持久化的参数。不可读取的参数会明确提示；命令、文件操作和运行时计数不会作为成像方案执行。不同相机、外触发模式或当前程序不支持的像素格式不会被当作兼容方案静默载入。

自动曝光、自动增益、自动白平衡开启时，自动产生的数值变化不会标记“临时修改”；模式开关或用户设置与保存方案不同则会标记。恢复手动曝光方案会同时关闭自动曝光并写回原曝光值。未启用的帧率限制及触发设置所产生的派生读数会记录，但不强制写回或用于修改判定。方案必须回读核对成功才显示一致；失败会尝试恢复原配置并暂停使用标定。

“方案管理”可以导出当前已保存方案、当前物镜全部方案或全部物镜与方案。载入 JSON 文件时可以合并或全部另存为新物镜；先导入库，再选择方案／点击“恢复已保存”应用，不会同时导入电脑处理或标定。标定库仍在测量页单独导入／导出，分别保留相机与采样匹配的记录。

电脑处理仅在当前会话生效，不写入物镜相机方案，重启从默认状态开始。保存、恢复或导入导出相机方案不会带入电脑处理；相机自身的 Gamma 属于相机参数，与电脑处理页的 Gamma 相互独立。“电脑处理 → 恢复默认 · 不做额外电脑处理”一次恢复全部 RGB、色阶、Gamma、亮度、对比度、饱和度、灰度及方向设置，不改相机或标定。原“重置直方图调整”仍只恢复色阶和 Gamma。

切换物镜／方案需要先停止录像和定时拍照；有测量或标注时可先保存图像再切换。冻结画面和本程序保存的离线图像保留原画面的物镜／参数记录及标定，不会套用新物镜。PNG／原始 TIFF 内记录实际使用的相机配置、方案版本和电脑处理；逐帧读数以 SDK 提供的 chunk 字段为准，其余字段为最近回读。原始 TIFF 像素保持不变。

已有配置首次写入前备份为 `settings/labview.before-objective-profiles.json`，保留旧物镜、标定、预设和快捷键。原来的混合预设只迁移相机部分，电脑处理不再随预设恢复。桌面的“2D Viewer（源码版）”入口使用本仓库最新源码；旧版安装包需另行构建才包含这些改动。

## 快捷键

在菜单“设置 → 快捷键设置…”中修改主快捷键和备用键。点击按键框后直接按下组合键，点击框内 × 清除；冲突时不能保存。“恢复默认”也需要点击“保存”才会生效。绑定随本机设置保存，重启后仍有效。

常用默认绑定：

| 操作 | 快捷键 |
| --- | --- |
| 打开图像／拍照填写文件名／切换到原始 TIFF 后拍照 | Ctrl+O／Ctrl+S／Ctrl+Shift+S |
| 按配置的目录和命名规则快速保存 | F9 |
| 冻结／恢复显示 | 空格 |
| 开始／停止录像（使用拍摄保存页的录像帧率） | Ctrl+Shift+R |
| 适应窗口／100%／放大／缩小 | 0／1／+ 或 =／- |
| 移动视野／选择标注／测量长度 | H／V／M |
| 标记点／文字说明／矩形框 | P／T／R |
| 撤销标注／删除所选对象／取消绘制或校准 | Ctrl+Z／Delete 或 Backspace／Esc |

删除快捷键在图像区域获得焦点时生效。输入框内的字母、数字和空格用于正常输入；弹窗内按键由弹窗处理。快捷键仅在本程序内生效，按住不重复触发。清空全部标注、重置处理参数和修改标定没有默认快捷键。

本机已准备的官方 PySpin wheel 约 67 MB，放在 `install`，由 Git 忽略；完成安装后可移走留作备份。Python、Qt、OpenCV、NumPy 和相机 SDK 的运行依赖仍需占用数百 MB，它们是正式程序运行所需。

本机开发目录的运行脚本会复用父目录已有的 `.venv-camera`；单独部署时优先使用本文件夹通过安装脚本创建的 `.venv`。
