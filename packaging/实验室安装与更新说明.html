2D Viewer 实验室安装与更新说明

适用：Windows 11 64 位 · FLIR Blackfly S BFS-U3-51S5C-C（USB3）
本次安装包：2D-Viewer-Setup-0.10.2-x64.exe

将安装包和本说明复制到实验室电脑即可开始安装。安装包包含 Python、界面和图像处理依赖，以及配套的官方相机软件安装程序；实验室电脑无需另外安装 Python、SpinPython 或 VS Code，安装过程无需联网。

首次安装

  1. 使用平时操作显微镜的 Windows 账户登录。退出 2D Viewer，并在 SpinView 中停止采集、断开相机连接。
  2. 双击 2D-Viewer-Setup-0.10.2-x64.exe，按安装向导继续。安装器检查 Spinnaker 运行库和 USB3 驱动；已存在匹配版本时跳过，缺少时启动随包附带的官方安装程序。安装驱动时可能需要管理员确认；若官方安装程序要求重启，先完成重启。
  3. 将相机直接接到电脑的 USB3／SS 接口，通过开始菜单或桌面的 2D Viewer 启动程序。如果没有自动连接，在“相机参数”中扫描并连接相机。

相机同一时间由一个程序使用。运行 2D Viewer 前，请先让 SpinView 或其他相机软件释放连接。

首次使用时检查画面、曝光、颜色和拍摄保存目录；测量前选择当前物镜，并检查对应标定是否有效。没有连接相机时，可以在主程序中用“打开图像…”查看、处理和标注已有图片。

当前版本的常用操作

  • 窗口上方只有一行工具栏。“设置”中可管理物镜和快捷键；工具栏的物镜下拉框用于选择实际使用的物镜。
  • 右侧“相机参数”中的相机方案按物镜保存曝光、增益、白平衡、像素格式等相机参数，不包含“电脑处理”的调整。相机或采样配置改变时，检查标定是否仍匹配。
  • “拍照”填写文件名并选择位置；“快速保存”（默认 F9）直接使用右侧“拍摄保存”配置的目录和命名规则。两个按钮共用文件格式与标注选项，命名预览可检查日期、序号和物镜倍数。
  • PNG 保留电脑处理后的画面；原始 TIFF 保留传感器像素。TIFF 勾选标注时只在文件内部记录信息，不把标注绘入原始像素。
  • 电脑处理页上下两个通道选择框同步；RGB 叠加时调节整体色阶。“恢复默认”可清除临时电脑处理，不修改相机参数或标定。

以后怎样更新

从 0.10.2 起，原 LabView 更名为 2D Viewer。直接运行新版安装包即可更新，原设置、物镜标定、相机方案和照片继续保留，无需先卸载。数据目录仍叫 LabView；从旧版更新时，程序也继续安装在原文件夹中。

  1. 取得新版 2D-Viewer-Setup-版本号-x64.exe，复制到实验室电脑。
  2. 使用与上次相同的 Windows 账户，关闭 2D Viewer。建议先按下文方法备份设置和标定。
  3. 直接运行新版安装包，安装完成后重新打开 2D Viewer。不用先卸载旧版。
  4. 确认保存目录和物镜标定仍正确，再继续使用。

安装器更新程序文件，保留该 Windows 账户的设置、标定、照片和日志。已匹配的相机运行库和驱动会跳过安装。保存在其他磁盘或自选文件夹中的照片继续留在原处，不会被安装器移动。

设置、照片在哪里，怎样备份

在文件资源管理器的地址栏粘贴以下路径并按回车。%LOCALAPPDATA% 会自动指向当前 Windows 账户的本地数据目录。

内容路径
程序文件%LOCALAPPDATA%\Programs\2D Viewer（从旧版更新时沿用原安装目录）
设置和物镜标定%LOCALAPPDATA%\LabView\settings\twodviewer.json
默认照片／录像目录%LOCALAPPDATA%\LabView\captures
运行和故障日志%LOCALAPPDATA%\LabView\logs

备份：关闭 2D Viewer，将 %LOCALAPPDATA%\LabView 整个文件夹复制到备份位置。若照片保存在自选目录，也要单独备份那个目录。只需要标定时，可以使用测量页的“导出标定库”。

恢复：关闭 2D Viewer，先保留一份当前设置，再把备份的 twodviewer.json（旧版为 labview.json）复制回 settings 文件夹。重新打开程序后检查拍摄目录。

卸载程序也会保留以上用户数据。不同 Windows 账户各自保存设置和标定；换账户或换电脑时需要单独迁移。

从之前的文件夹版本迁移

如果此前用 Start 2D Viewer.cmd 启动，旧设置位于 LabView-App 文件夹中；新克隆源码版位于 data 中。只有第一次换到安装版时需要以下步骤：

  1. 关闭旧版 2D Viewer，备份旧文件 LabView-App\settings\labview.json。
  2. 安装新版，启动一次后关闭，让程序建立新的数据目录。
  3. 打开 %LOCALAPPDATA%\LabView\settings。先备份其中已有的 labview.json，再将旧文件复制为 twodviewer.json（已有旧版 labview.json 也继续识别）。
  4. 重新启动 2D Viewer，检查物镜标定和拍摄保存目录。旧电脑的盘符、文件夹在实验室电脑上可能不存在，需要重新选择。

旧照片不会自动迁移：可以自行复制到新目录，也可以继续使用原来的照片目录。相机、采样方式或显微镜光路发生变化时，应重新核准对应标定；保存的“每像素长度”不能直接用于不同光学配置。

遇到问题时

能打开程序，但找不到相机

先关闭占用相机的其他软件，检查电源、相机线和 USB3／SS 接口，然后重新扫描。若仍找不到，关闭 2D Viewer，用官方 SpinView 检查；SpinView 也无法出图时，先处理驱动或连接问题。

安装中需要管理员权限或重启

这是官方相机驱动或系统运行库的安装要求。使用实验室允许的管理员账户完成驱动安装；重启后，用日常操作相机的 Windows 账户启动 2D Viewer。

安装失败，或提示相机运行库版本不匹配

本安装包配套 Spinnaker 4.4.0.246。先记录错误码并重启电脑，再运行安装包。如果电脑已安装其他版本的 Spinnaker，请先确认该版本是否被实验室其他程序使用，再由管理员处理版本兼容；不要直接删除已有驱动。安装日志通常位于当前账户的临时目录，在资源管理器中输入 %TEMP%，查找最新的 Setup Log 文件。

换了电脑后无法保存，或标定显示不匹配

重新选择当前电脑上可写入的拍摄目录。标定不匹配时，核对物镜、相机及采样设置，并为当前配置选择或重新建立标定。

程序报错或闪退

保留错误截图，并复制 %LOCALAPPDATA%\LabView\logs 中的日志；同时记录所用安装包的版本号，便于定位问题。不要为排查问题删除标定和照片。
